# samples/

Папка для эталонных и тестовых материалов.

**Реальные клиентские файлы (спецификации, письма, готовые КАЦ/ТКП) сюда НЕ коммитятся** —
они конфиденциальны. Кладите их в `samples/private/` (эта папка в `.gitignore`).

Эталонный образец формата использовался при разработке сборщиков, но в репозиторий не включён.
Для проверки форматов без клиентских данных есть синтетический прогон:

```bash
cd <корень репозитория>
python -m engine.demo_run
```

Он создаёт в `engine/data/output/`: `KAC_demo.xlsx`, `TKP_demo.pdf`, `TSN_demo.xlsx`.
