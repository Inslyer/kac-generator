# КАЦ-генератор — конъюнктурный анализ цен

Веб-приложение для сметчика: по спецификации оборудования (РД, в т.ч. сканы) и письмам с ценами
на уникальное оборудование автоматически формирует три файла в формате эталонного образца:

1. **Том ТКП** (PDF) — скриншоты карточек товара + панели реквизитов продавца.
2. **КАЦ** (Excel) — структурированный конъюнктурный анализ (по 3 макс. цены на позицию).
3. **Файл ТСН-2001** (Excel) — сравнение с расценками ТСН-2001 (mos.ru) + фильтрация.

## Архитектура

- **`web/`** — статический интерфейс (Vite + React), деплоится на **GitHub Pages**.
- **`engine/`** — локальный движок (Python + FastAPI + Playwright), запускается на машине сметчика.
  Делает тяжёлую работу: парсинг PDF, поиск цен, скриншоты, парсинг mos.ru, сборку выходных файлов.
  Реальный браузер + российский IP позволяют обходить антибот-защиту магазинов и mos.ru.

UI обращается к движку по `http://127.0.0.1:8765`.

## Быстрый старт (локально)

```bash
# 1. Движок
cd engine
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env          # заполнить ключи: ANTHROPIC_API_KEY, DADATA_TOKEN
uvicorn app:app --port 8765

# 2. Интерфейс (в отдельном терминале)
cd web
npm install
npm run dev
```

Подробности — в [`docs/INSTRUCTION.md`](docs/INSTRUCTION.md).

## Ключи и сервисы

| Переменная | Назначение | Где взять |
|---|---|---|
| `ANTHROPIC_API_KEY` | структуризация спецификации, разбор писем, матчинг | console.anthropic.com |
| `DADATA_TOKEN` | реквизиты по ИНН (наименование/КПП/адрес) | dadata.ru (есть бесплатный тариф) |
| `YANDEX_SEARCH_API_KEY` | (опц.) поиск; иначе поиск через браузер | yandex.cloud |
