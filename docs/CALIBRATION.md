# Калибровка на реальных данных

Сетевые/LLM-этапы (разбор PDF через Claude, автопоиск цен, скриншоты, mos.ru) работают только
на вашей машине — с ключами, установленным браузером и российским IP. Для пошаговой проверки
есть диагностический инструмент `engine/calibrate.py`.

## Подготовка

```bash
cd engine
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env        # впишите ANTHROPIC_API_KEY и DADATA_TOKEN
```

## Запуск диагностики (из корня репозитория)

```bash
# только разбор спецификации:
python -m engine.calibrate --spec "путь/Спецификация_АК.pdf" --discipline АК

# спецификация + письма + поиск по 2 позициям + проверка mos.ru:
python -m engine.calibrate \
  --spec "путь/Спецификация_ЭМ.pdf" --discipline ЭМ \
  --letter "путь/Счет.pdf" \
  --search 2 --tsn

# производители уникального оборудования (не искать онлайн) задаются в .env: CUSTOM_MAKERS=ЗаводА;ЗаводБ
# либо через --unique "подстрока1; подстрока2"
```

Инструмент печатает отчёт по этапам (✓/⚠/✗). **Скопируйте вывод и пришлите** — по нему
откалибруем промпты и селекторы.

## Что проверяем на каждом этапе

1. **Окружение** — заданы ли ключи, установлен ли браузер.
2. **Разбор спецификации** — тип файла (текст/скан), число и состав позиций, верно ли помечены
   уникальные (из писем). Сверьте с эталоном ниже.
3. **Письма** — извлечены ли цены и ИНН поставщика.
4. **Онлайн-поиск** — сколько источников найдено (цель ≥12), регион складов (Москва/МО), цены,
   ИНН, сделаны ли скриншоты.
5. **ТСН-2001** — получен ли коэффициент пересчёта с mos.ru и расценка по позиции.

## Признаки корректного разбора спецификации

На текстовом PDF (есть текстовый слой) таблица обычно извлекается чисто. Проверьте:
- Число основных позиций совпадает с бумажной спецификацией.
- Подпозиции «в составе» (компоненты комплекта) **свёрнуты** в родительскую позицию, а не
  вынесены отдельными строками.
- Позиции с заводом-изготовителем из `CUSTOM_MAKERS` (или подходящие под `--unique`) помечены
  `[УНИК.]` — это оборудование спецзаказа, цена берётся из писем, онлайн-поиск не выполняется.
- Остальные позиции — обычные, идут в онлайн-поиск.

## Спецификация-скан

Если спецификация — **скан без текстового слоя**, распознавание идёт через Claude vision (рендер
страниц в PNG, tesseract не требуется). Проверьте, что число позиций и наименования совпадают с
бумажной спецификацией; на сканах возможны ошибки распознавания — правьте в таблице UI.

## Типичные точки калибровки

- **Поиск даёт <12 источников** — расширить список запросов (`engine/search/agent.py:build_queries`)
  или поисковых доменов; часть позиций добивать вручную (кнопка 📷 по найденному URL).
- **Регион не Москва/МО** — логика в промпте `EXTRACT_SYSTEM`; в UI склад правится вручную и
  не-московские строки подсвечиваются.
- **mos.ru не парсится** — структура страницы могла измениться; селекторы/промпт в
  `engine/tsn/mos_ru.py`. Фолбэк — ручной ввод базовой расценки и коэффициента в таблице.
- **Реквизиты по ИНН пустые** — проверьте `DADATA_TOKEN` (графы K/L/M/O в КАЦ).
