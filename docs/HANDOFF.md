## Как запускать (важно — НЕ через run.sh)
- **Запуск:** двойной клик по **`start.command`** в корне репо (из Finder). Использует готовое
  окружение `engine/.venv`, поднимает движок в графической сессии пользователя и сам открывает
  браузер (через ~3 сек → http://127.0.0.1:8765/).
- Эквивалент в терминале:
  `cd /Users/yuriy/Documents/Claude/KA && ./engine/.venv/bin/python -m uvicorn engine.app:app --host 127.0.0.1 --port 8765`
- **`run.sh` НЕ использовать** — зависает на повторной проверке pip/playwright.
- Окружение уже установлено: `engine/.venv` (зависимости + Chromium + `ocrmac`). Ключи в `engine/.env`:
  `LLM_PROVIDER=deepseek`, `DEEPSEEK_API_KEY` задан и проверен; `ANTHROPIC_API_KEY` тоже есть (фолбэк);
  `DADATA_TOKEN` задан; `YANDEX_*` не используются.

## Что РАБОТАЕТ вживую (проверено)
- **Распознавание спецификации** (`POST /parse`): текстовые PDF напрямую; **сканы → локальный OCR**
  (`engine/parsers/spec_pdf.py`, `_ocr_backend()`): на macOS — **Apple Vision** (пакет `ocrmac`, без
  Homebrew/системных зависимостей), на Linux/VPS — Tesseract. OCR-текст → DeepSeek. Claude vision
  остаётся фолбэком только при `LLM_PROVIDER=anthropic`.
- **Поиск цен** (`POST /search_position`): находит реальные офферы со скриншотами, городом, ИНН.
  Извлечение цены/региона/ИНН — DeepSeek. `MIN_SOURCES=5` (было 12; число тянется из `/health` в UI).
  Источник — выдача Yandex через Playwright (headed). Капча решается **один раз вручную** в видимом
  окне Chromium; cookie в `engine/data/cache/cookies.json` (storage_state) → дальше без капчи.
  Диагностика: строки `[поиск] …` в окне движка (сколько ссылок, почему 0 офферов).
- **Реквизиты продавца** (`engine/requisites/supplier.py`): добираются с сайта магазина (контакты/
  подвал), ИНН-regex ловит верстку с пробелами, берётся окно вокруг ИНН. В Том ТКП пишутся
  **текстом** (Наименование/ИНН/КПП) — скриншот реквизитов больше не снимается. Диагностика:
  строки `[реквизиты] …` в окне движка.
- **Сборка** КАЦ/ТКП/ТСН и фильтр «ТСН>КАЦ → исключить» — готовы и протестированы
  (`engine/builders/*`; тесты `engine/test_build_manual.py`, `engine/test_endpoints.py`, `demo_run.py`).
- **UI** (`web/index.html`, `web/app.js`): 3 шага (параметры+файлы → таблица позиций/цен → сборка),
  миниатюры скриншотов с зумом, «найти цены» по одной и «по всем», индикатор источников N/M (M из
  `/health`), редактируемый «город склада» с подсветкой не-Москвы. Шапка показывает активный
  провайдер (DeepSeek/Claude) и статус OCR.

## Важные gotchas (не наступать повторно)
- **Движок запускать из сессии пользователя** (`start.command`), иначе окно Playwright-Chromium
  невидимо и капчу не решить. Фоновый запуск ассистентом для поиска не годится.
- **UI открывать с движка** (`http://127.0.0.1:8765/`), не с https-Pages — иначе Safari блокирует
  обращения к http-localhost (mixed content).
- **`/parse` блокирует event loop** (async-эндпоинт зовёт синхронный `parse_spec`) — во время разбора
  движок не отвечает (в т.ч. `/health`). Кандидат на улучшение: вынести в threadpool.
- **Yandex Search API недоступен** для новых аккаунтов (есть только AI Studio / Vector Store — это
  поиск по своим файлам, не веб-поиск). Поэтому поиск — через браузер + cookie-капча. Код API
  (`engine/search/search_engine.py:yandex_api_search`) оставлен на случай появления ключа.
- Конфиденциальные данные обезличены; «уникальные» производители задаются через `CUSTOM_MAKERS` в `.env`.

## ТСН-2001 — решено (локальный справочник)
Логика: `ТСН_тек = база × коэффициент`; если `ТСН_тек > макс. цена КАЦ` → позиция исключается из КАЦ
и помечается в файле ТСН. Реализовано через **локальные справочники** в корне репо
(`engine/tsn/local_db.py`): базовая расценка из `ТСН-2001_электро_автоматика.md` (LLM-матчинг),
коэффициент из `индексы.md`. Пути — в `config.py` (`TSN_REFERENCE_FILE`, `TSN_INDICES_FILE`).
`mos.ru` (`engine/tsn/mos_ru.py`) больше не используется (недоступен под VPN). Индексы по видам
работ заполняются в `индексы.md` вручную раз в квартал (незаполненные фолбэчат на «оборудование»).
