- Закончились кредиты Anthropic → переключились на **DeepSeek** (`LLM_PROVIDER=deepseek` в `.env`,

## Что РАБОТАЕТ вживую (проверено)
- **Распознавание спецификации** (`POST /parse`): принимает **PDF, DOCX, XLSX/XLS** (диспетчер по
  расширению в `spec_pdf.parse_spec`; DOCX — python-docx, XLSX — openpyxl). Текстовые PDF напрямую;
  **сканы → локальный OCR** (`_ocr_backend()`): macOS — Apple Vision (`ocrmac`, без Homebrew),
  Linux/VPS — Tesseract. OCR-текст → DeepSeek. Claude vision — фолбэк только при `LLM_PROVIDER=anthropic`.
- **База-кэш позиций** (`engine/search/base_db.py`): результаты поиска (цены/скриншоты/реквизиты)
  кэшируются в `engine/data/base/index.json` и переиспользуются. Поиск **cache-first**: сперва
  `base.lookup` (без браузера), вживую — только промахи (и они пополняют базу). Матчинг позиции:
  точный нормализованный ключ (имя|марка|дисциплина) → LLM-фолбэк (DeepSeek). Дата в документах
  всегда текущая. Управление: `/base`, `/base/refresh` (фоновая джоба), `/base/add`, `DELETE /base/{key}`;
  в UI карточка «База цен». Обновлять раз в месяц кнопкой (cron — после VPS).
- **Поиск цен** (`POST /search_position`): выдача через **SERP-API XMLRiver** (без капчи, ключи в
  `.env`), браузер только для скриншотов карточек (headless, `BROWSER_HEADED=false`). Сначала ищет
  по **доверенным поставщикам** (`Поставщики.md`, `site:`-выдача), интернет — добор если офферов
  <`TOP_PRICES`. Извлечение цены/региона/ИНН — DeepSeek. Капча-страницы магазинов отсекаются
  (`_looks_like_bot_check`), ИНН проверяется по контрольным цифрам (`valid_inn`). `MIN_SOURCES=5`,
  `TOP_PRICES=3`. Диагностика `[поиск]`/`[реквизиты]` в окно движка.
- **Реквизиты продавца**: для доверенных поставщиков берутся из `Поставщики.md`; иначе добираются
  с сайта магазина (`engine/requisites/supplier.py`). В Том ТКП пишутся **текстом** (Наименование/
  ИНН/КПП) — скриншот реквизитов не снимается.
- **Сборка** КАЦ/ТКП/ТСН и фильтр «ТСН>КАЦ → исключить» — готовы и протестированы
  (`engine/builders/*`; тесты `engine/test_build_manual.py`, `engine/test_endpoints.py`, `demo_run.py`).
- **UI** (`web/index.html`, `web/app.js`): 3 шага (параметры+файлы → таблица позиций/цен → сборка)
  + карточка «База цен». Миниатюры скриншотов с зумом, «найти цены» по одной и «по всем», индикатор
  источников N/M (из `/health`), город склада с подсветкой не-Москвы. Шапка показывает провайдер
  (DeepSeek/Claude), статус OCR, число источников. Загрузка спецификаций фильтруется по расширению.

## Важные gotchas (не наступать повторно)
- **UI открывать с движка** (`http://127.0.0.1:8765/`), не с https-Pages — иначе Safari блокирует
  обращения к http-localhost (mixed content).
- **`/parse` блокирует event loop** (async-эндпоинт зовёт синхронный `parse_spec`) — во время разбора
  движок не отвечает (в т.ч. `/health`). Кандидат на улучшение: вынести в threadpool.
- **Выдача — через XMLRiver** (SERP-API, ключи в `.env`), капчи нет. Официальный Yandex Search API
  новым аккаунтам недоступен; браузерный поиск выдачи остался лишь крайним фолбэком. Браузер нужен
  только для скриншотов карточек (headless ок; магазины капчу обычно не показывают — кто показывает,
  отсекается). Старый `cookies.json` от ручной капчи больше не критичен.
- **После правок `.env` или кода — перезапуск движка** (`start.command`), статичный JS — Cmd+Shift+R.
- Конфиденциальные данные обезличены; «уникальные» производители задаются через `CUSTOM_MAKERS` в `.env`.

## ТСН-2001 — решено (локальный справочник)
Логика: `ТСН_тек = база × коэффициент`; если `ТСН_тек > макс. цена КАЦ` → позиция исключается из КАЦ
и помечается в файле ТСН. Реализовано через **локальные справочники** в корне репо
(`engine/tsn/local_db.py`): базовая расценка из `ТСН-2001_электро_автоматика.md` (LLM-матчинг),
коэффициент из `индексы.md`. Пути — в `config.py` (`TSN_REFERENCE_FILE`, `TSN_INDICES_FILE`).
`mos.ru` (`engine/tsn/mos_ru.py`) больше не используется (недоступен под VPN). Индексы по видам
работ заполняются в `индексы.md` вручную раз в квартал (незаполненные фолбэчат на «оборудование»).
