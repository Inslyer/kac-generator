# Инструкция сметчику

## Что делает приложение

По спецификации оборудования (рабочая документация, в т.ч. сканы) и письмам с ценами на
уникальное оборудование формирует три файла:

1. **Том ТКП** (PDF) — скриншоты карточек товара с сайтов + панели реквизитов продавцов.
2. **КАЦ** (Excel) — конъюнктурный анализ: по 3 максимальные цены на позицию (самовывоз Москва/МО),
   цена без НДС, реквизиты, ссылки, № страницы в Томе ТКП.
3. **Файл ТСН-2001** (Excel) — сравнение с расценками ТСН-2001 (с коэффициентом пересчёта с mos.ru).
   Если расценка ТСН-2001 выше цены КАЦ — позиция исключается из КАЦ.

## Один раз: настройка движка на вашем компьютере

1. Установите Python 3.11+ и (для Windows) разрешите запуск скриптов.
2. В папке `engine/` запустите:
   - Windows: двойной клик по `run.cmd`
   - macOS/Linux: `./run.sh`
3. При первом запуске создастся файл `engine/.env`. Откройте его и впишите:
   - `ANTHROPIC_API_KEY` — ключ Claude (console.anthropic.com)
   - `DADATA_TOKEN` — токен DaData (dadata.ru, бесплатный тариф)
4. Перезапустите движок. В окне должно появиться: `Движок: http://127.0.0.1:8765`.

> Движок открывает реальный браузер на вашем компьютере (российский IP) — так магазины и mos.ru
> не блокируют автопоиск. Окно браузера во время работы можно не трогать.

## Каждый раз: формирование документов

1. Откройте интерфейс (адрес GitHub Pages вашего репозитория).
2. Убедитесь, что вверху написано «движок на связи».
3. Заполните: наименование объекта, дисциплину (ЭМ/АК), дату фиксации.
4. В поле «Уникальное оборудование» перечислите подстроки наименований, цены на которые берутся
   из писем (например: `щит спецзаказа; уникальный модуль`). Такие позиции не ищутся в интернете и не попадают
   в Том ТКП.
5. Загрузите спецификации и письма (PDF).
6. Нажмите «Сформировать документы». Следите за прогрессом и логом.
7. По готовности скачайте три файла.

## Важные правила (заложены в логику)

- Цены — максимально высокие: проверяется ≥12 источников, берутся 3 наибольшие.
- Подходят только предложения с самовывозом из Москвы/МО (поставщик может быть из любого региона).
- НДС = 22% (графа «без НДС» = цена / 1.22).
- Цены из писем идут в КАЦ одной строкой и НЕ попадают в Том ТКП.
- Если ТСН-2001 > КАЦ — позиция исключается из КАЦ (и помечается в файле ТСН).

## Если что-то не нашлось

Если по позиции не набралось 12 источников или не определился регион/реквизиты — позиция
помечается в логе. Такие позиции дорабатываются вручную (на следующих итерациях добавим
ручную правку прямо в интерфейсе).
