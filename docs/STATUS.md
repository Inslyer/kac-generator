# Статус прототипа

> **Вживую подтверждено:** распознавание спецификации (текст + сканы через локальный OCR), поиск цен
> с реальными офферами/скриншотами/городом/ИНН (через DeepSeek), реквизиты продавца текстом в ТКП,
> обход капчи (cookies). Запуск — `start.command`, UI с движка (`http://127.0.0.1:8765/`).
> **LLM = DeepSeek** (`LLM_PROVIDER=deepseek`), сканы — локальный OCR (Apple Vision/`ocrmac`).
> Подробности — в [`HANDOFF.md`](HANDOFF.md).


## Готово и проверено (детерминированное ядро, без сети)

- **Модели данных** (`engine/models.py`) — позиции, офферы, реквизиты, строки ТСН.
- **Сборщик КАЦ** (`engine/builders/kac_xlsx.py`) — формат эталонного образца 1-в-1: 17 колонок A–Q,
  блоки по 3 строки, объединения A..J, графа H = G/1.22 (НДС 22%), графа Q = № страницы ТКП,
  гиперссылки, позиции из писем одной строкой. ✓ сверено с эталоном.
- **Сборщик Тома ТКП** (`engine/builders/tkp_pdf.py`) — обложка + страница на позицию (3 пары
  «карточка товара + реквизиты»), реквизиты продавца **текстом** (Наименование/ИНН/КПП), шапка
  «Дата фиксации», подвал «НДС 22%», кириллический шрифт. ✓ рендер.
- **Сборщик ТСН + фильтр** (`engine/builders/tsn_xlsx.py`) — расчёт «ТСН в текущих ценах»,
  %, решение, исключение позиций ТСН>КАЦ из КАЦ. ✓ проверено.
- **Сквозной демо-прогон** (`engine/demo_run.py`) — собирает все 3 файла на синтетике. ✓
- **Интерфейс** (`web/index.html`, `web/app.js`) — трёхшаговый поток: параметры+файлы →
  редактируемая таблица позиций/цен → сборка. Миниатюры скриншотов в строке оффера с зумом,
  кнопки «📷 снять скриншот» (по URL) и «🔎 найти цены» (по позиции). ✓ проверено в превью.
- **Деплой UI** — GitHub Actions → Pages (`.github/workflows/pages.yml`).
- **Движок** — FastAPI (`engine/app.py`): `/parse`, `/build`, `/capture`, `/search_position`,
  `/cache/{name}` (отдача скриншотов, защита от обхода каталогов) + оркестратор (`engine/pipeline.py`).
- **Ручной режим без сети** — `skip_search` + ручные цены/расценки ТСН. Скриншоты, заданные/найденные
  в таблице, пробрасываются в Том ТКП. ✓ тесты `engine/test_build_manual.py`, `engine/test_endpoints.py`.

## LLM-слой (`engine/llm.py`)

- Провайдер выбирается `LLM_PROVIDER` (.env): **`deepseek`** (активен) или `anthropic`.
- DeepSeek — через OpenAI-совместимый endpoint (httpx, JSON-режим), модель `deepseek-chat`. Без vision.
- Сканы спецификаций распознаёт **локальный OCR** (`spec_pdf._ocr_backend`): Apple Vision (`ocrmac`,
  macOS) → Tesseract (Linux). Claude vision — фолбэк только при `LLM_PROVIDER=anthropic`.

## Реализовано, требует боевой проверки на масштабе

- **Парсер спецификации** (`engine/parsers/spec_pdf.py`) — PyMuPDF + локальный OCR + LLM.
- **Парсер писем** (`engine/parsers/letters.py`) — LLM.
- **Поисковый агент** (`engine/search/`) — браузерная выдача Yandex + извлечение цены/региона/ИНН
  со страницы (DeepSeek) + скриншот карточки. Диагностика `[поиск] …` в окне движка.
- **Реквизиты продавца** (`engine/requisites/supplier.py`) — добор с сайта магазина, в ТКП текстом.
  `dadata.py` (DaData по ИНН) — опционально, если задан токен.
- **ТСН-2001** — локальный справочник (`engine/tsn/local_db.py`); `mos_ru.py` не используется.
