# Статус прототипа

## Готово и проверено (детерминированное ядро, без сети)

- **Модели данных** (`engine/models.py`) — позиции, офферы, реквизиты, строки ТСН.
- **Сборщик КАЦ** (`engine/builders/kac_xlsx.py`) — формат эталонного образца 1-в-1: 17 колонок A–Q,
  блоки по 3 строки, объединения A..J, графа H = G/1.22 (НДС 22%), графа Q = № страницы ТКП,
  гиперссылки, позиции из писем одной строкой. ✓ сверено с эталоном.
- **Сборщик Тома ТКП** (`engine/builders/tkp_pdf.py`) — обложка + страница на позицию (3 пары
  «карточка + реквизиты»), шапка «Дата фиксации», подвал «НДС 22%», кириллический шрифт. ✓ рендер.
- **Сборщик ТСН + фильтр** (`engine/builders/tsn_xlsx.py`) — расчёт «ТСН в текущих ценах»,
  %, решение, исключение позиций ТСН>КАЦ из КАЦ. ✓ проверено.
- **Сквозной демо-прогон** (`engine/demo_run.py`) — собирает все 3 файла на синтетике. ✓
- **Интерфейс** (`web/index.html`, `web/app.js`) — трёхшаговый поток: параметры+файлы →
  редактируемая таблица позиций/цен → сборка. Миниатюры скриншотов в строке оффера с зумом,
  кнопки «📷 снять скриншот» (по URL) и «🔎 найти цены» (по позиции). ✓ проверено в превью.
- **Деплой UI** — GitHub Actions → Pages (`.github/workflows/pages.yml`).
- **Движок** — FastAPI (`engine/app.py`): `/parse`, `/build`, `/capture`, `/search_position`,
  `/cache/{name}` (отдача скриншотов, защита от обхода каталогов) + оркестратор (`engine/pipeline.py`).
- **Ручной режим без сети** — `skip_search` + ручные цены/расценки ТСН. Скриншоты, заданные/найденные
  в таблице, пробрасываются в Том ТКП. ✓ тесты `engine/test_build_manual.py`, `engine/test_endpoints.py`.

## Реализовано, требует боевой проверки с ключами и российским IP

- **Парсер спецификации** (`engine/parsers/spec_pdf.py`) — PyMuPDF + OCR-ветка + Claude.
- **Парсер писем** (`engine/parsers/letters.py`) — Claude.
- **Поисковый агент** (`engine/search/`) — Yandex API / браузерная выдача + извлечение цены,
  региона, ИНН со страницы (Claude) + скриншоты.
- **Реквизиты** (`engine/requisites/dadata.py`) — DaData по ИНН + скриншот панели (Checko).
- **ТСН-2001 mos.ru** (`engine/tsn/mos_ru.py`) — Playwright-обход + Claude-матчинг расценок.
